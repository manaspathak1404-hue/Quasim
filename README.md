# Quasim
Quasim is a low level quantum simulator designed to mimic the features of a quantum computer. At this current moment this project only has  a harware checker that check your hardware and qubit requirement that your system can process by scaling the amplitudes by 2^N and then multiplies it by size of complex<double> object. It compares the required storage with R.A.M available in your system and lefts 1 Gib i.e. 1024^3 bytes.
# How to use this project 
In order to use this project you have to input the number of qubits you want to process and then it checks your system and tell if the desired amount of qubits are possible or not.
