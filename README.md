# Quasim
Quasim is a low level quantum simulator designed to mimic the features of a quantum computer. Quasim is equipped a hardware checker that check your hardware and qubit requirement that your system can process by scaling the amplitudes by 2^N and then multiplies it by size of complex<double> object. It compares the required storage with R.A.M available in your system and lefts 1 Gib i.e. 1024^3 bytes. This simulator asks the user about what process they want to initiate and processes it. At this moment only Pauli X(NOT gate) is only added and soon gates like Hadamard will be added
# How to use this project 
In order to use this project you have to input the number of qubits you want to process and then it checks your system and tell if the desired amount of qubits are possible or not. Once you enter the valid number of qubit, It asks you for what process to initiate and right now only close and Pauli X are available
